Eight Bus

EIGHT BUS

A synth built for the Akai MIDImix: eight strips, one patch bay.

Press Power, then Connect MIDImix. Press Send All on the unit once to read its knob positions.

Patch cables

Notes (for strips armed with REC)

A keyboard plugged in alongside the MIDImix, like a Swing, plays armed strips too. So do the Z and Q key rows here, with ↑ ↓ for octave and ← → for bend.

Ways to use it

  • No-input mixer. The MIDImix is a mixer, so treat it like one: filters feeding themselves and each other, no oscillators at all. Faders set the pitch and the growl. Start from No-Input Mixer.
  • Drone instrument with no keyboard. Every strip holds a note, and you play by mixing them. Good for ambient sets or under a guitar. Start from Drone Choir.
  • Eight-track groove box. Each strip is a drum or synth track on its own Euclidean pattern, with different lengths drifting against each other. Mute, drop and rebuild it live. Start from Euclid Kit or Dub Stabs.
  • Hardware panel for a keyboard. Plug in the Swing too. Armed strips become voices, and the MIDImix is the front panel. Start from Keyboard Poly.
  • Patch-bay practice. Learn modular routing with real buttons. Any strip into any other, with no cables to buy.

The patch bay on the hardware

  • Press Bank Right until the PATCH page is up.
  • Press REC on a strip: that strip is now the source. Its REC lights.
  • The MUTE lights now show where that source goes. Press a MUTE to connect or disconnect that strip.
  • Turn that strip's top knob to set how much signal the cable carries.
  • A strip can patch into itself, which is how feedback starts.

Audio cables feed a strip's input (the table below says what that does). Cables from an LFO strip move its main setting instead: usually pitch or cutoff. Cables are post-fader, so a strip's fader also sets what it sends.

About this

MIDI can't connect inside the claude.ai viewer. To use a MIDImix, open nokill-pedal-co.github.io/eight-bus in Chrome or Edge.

Eight Bus assumes the MIDImix's factory settings: channel 1, buttons sending notes. Akai doesn't publish the map, so it comes from the open-source akai-midimix library and Ardour's MIDImix map. If you've changed the unit with Akai's editor, restore the defaults. Not affiliated with Akai Professional.
